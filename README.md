# MÔ HÌNH 3D NHÀ MÁI THÁI (REACT + VITE + THREE.JS)
### Kích Thước: 25.98m × 9.50m (5 Ô Nhịp - 6 Hàng Cột)

Dự án đã được chuyển đổi hoàn toàn sang **React + Vite + Three.js** với tính năng **Hot Module Replacement (HMR)** giúp cập nhật và render trực tiếp trên trình duyệt khi chỉnh sửa mã nguồn.

---

## 🛠️ Thông Số Kỹ Thuật Đã Cập Nhật

- **Chiều dài nhà:** 25.98 m
- **Chiều rộng nhà:** 9.50 m
- **Diện tích sàn:** 246.81 m² (Tầng trệt hoàn toàn trống suốt)
- **Kích thước cột:** **20cm × 20cm (0.20m × 0.20m)**
- **Chiều cao cột:** **3.80 m (3m8)**
- **Chiều cao đỉnh nóc:** **6.60 m** (Mái Thái dốc chữ A dập sóng tôn chống nóng)
- **Hệ thống cột:** 6 hàng cột chịu lực 2 bên, chia đều thành **5 ô nhịp** (5.196 m / ô)
- **Vỉa hè mặt bên:** **4.00 m** (Từ tường hông dài 25.98m ra mép viền đỏ)
- **Vỉa hè / Sân mặt trước:** **12.00 m** (Từ mặt tiền nhà ra mép viền đỏ)
- **Mép viền đỏ:** Bó vỉa vỉa hè nổi viền đỏ đặc trưng, bo cong góc góc ngã rẽ
- **Đường xe chạy (Phần xanh):** Mặt đường nhựa asphalt xe chạy với 2 tuyến đường nhánh xanh theo bản vẽ phác thảo

---

## 🚀 Hướng Dẫn Khởi Chạy

### Cách 1: Chạy bằng dòng lệnh (Khuyên dùng)
```bash
npm run dev
```
Trình duyệt sẽ tự động mở tại: `http://localhost:5180`.

*(Lưu ý trên PowerShell Windows nếu gặp chính sách ExecutionPolicy, bạn có thể chạy: `npm.cmd run dev`)*

### Cách 2: Nhấp đúp chuột vào file `start.bat`
- Nhấp đúp chuột vào file **`start.bat`** trong thư mục `E:\MoHinhNha3D`.

## 🌟 Các Tính Năng Nổi Bật

1. **Render trực tiếp khi chỉnh sửa (Hot Reload):**
   - Mọi thay đổi trong `src/core/houseModel.js`, `src/core/dimensions.js`, `src/App.jsx`... sẽ tự động cập nhật ngay trên trình duyệt mà không cần tải lại trang.
2. **Kích thước cột chuẩn:**
   - 6 cặp cột chịu lực tiết diện đúng 20cm × 20cm, cao 3.80m.
3. **Quy hoạch khuôn viên theo phác thảo:**
   - Vỉa hè lát gạch 4.00m bên hông và 12.00m phía trước.
   - Gờ bó vỉa mép viền đỏ nổi bật bo góc tròn mềm mại.
   - Tuyến đường xe chạy và 2 nhánh đường màu xanh cho xe lưu thông.
4. **Thước đo kích thước 3D trực quan:**
   - Đầy đủ các thẻ đo: Chiều dài 25.98m, Rộng 9.50m, 5.196m / ô, Cao cột 3.80m, Đỉnh mái 6.60m, Vỉa hè hông 4.00m, Vỉa hè trước 12.00m, Đường xe chạy.
5. **Mở mái / Nhìn xuyên thấu & Đổi màu tôn mái & Chế độ ngày đêm & Chụp ảnh HD.**
